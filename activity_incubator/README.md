# Greia Activity incubator

Source-review candidates live here **before** first-party production admission.
They are intentionally outside `activities/`, Greia built-in registry discovery,
official release staging, spoken-label completeness audits and child catalogues.

Promotion requires: canonical manifest validation, bilingual pronunciation/title
recordings, genuine pre-reader instructions, source tests, child usability review,
exact-SHA Simulator/visual/audio evidence, explicit first-party readiness-list
reconciliation, and curated release decision. Never bypass these by relaxing the
production test gates.

`tempo_di_greia/` is the first candidate: analog/digital clock, separate
practice clock, stopwatch and bounded countdown. It does not run background
alarms, set OS time, or interact with parent time limits. Its icon WebP
is a candidate rendition derived from the packaged SVG, not final art.
