# Greia Encyclopedia — contributor and authoring guide

The Greia Encyclopedia's public research source is kept under `encyclopedia/research/`; its child-facing Activity is `activities/enciclopedia_greia/`.

Research pages are editorial source material, not automatically verified or final child-facing copy. Contributors should check the factual claims, readability and asset provenance before updating runtime content.

## Where to start

1. Read [AGENTS.md](../AGENTS.md) and [CONTRIBUTING.md](../CONTRIBUTING.md).
2. Read the [Activity authoring skill](../skills/greia-activity-authoring/SKILL.md) and [visual authoring skill](../skills/greia-visual-authoring/SKILL.md).
3. For speech work, use the [voice production skill](../skills/greia-voice-production/SKILL.md) and [voice engine reference](../tools/greia_voice_core/README.md).
4. Make the change in the appropriate research page or Activity source, review provenance, and test in the Simulator. Distinguish source review from verified runtime behavior in the PR.

The former implementation plan, recording queue, progress journal and owner handover were internal work coordination rather than public authoring specifications and are no longer tracked at the current public branch head. This does not change the Encyclopedia runtime or research material.
