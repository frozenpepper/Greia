# Parent artwork

`greia-constellation.png` is an unchanged copy of the owner-selected Greia OS
`assets/boot/frames/frame_0051.png`, reused for this Parent redesign on 2026-09-08.
The OS source artwork remains authoritative. CSS frames the constellation in the
navigation brand and displays the complete artwork beside desktop setup forms.
No image generation, third-party asset, network fetch, or animation is used.

The image pin tool includes it in the runtime integrity manifest only when a
runtime file references it (`python3 tools/update_parent_client_pin.py`).
