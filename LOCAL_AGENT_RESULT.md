## 4. Shell Integration Details

- **Semantic Asset ID:** `ui.shadow.soft`, `variant="default"`.
- **Target Seam:** `GreiaLauncherPresentation._draw_activity_tile_content`.
- **Positioning:** Grounded at tile base (`shadow_top = target.bottom - int(shadow_h * 0.40) + int(round(motion.shadow_lift * 0.45))`), width matches tile (`shadow_w = target.width`).
- **Cache Management:** Bounded 12-entry LRU `PygameVisualSurfaceCache` with 1024x600 per-surface pixel ceiling, scaled once on miss, invalidated on window/viewport resize.
- **Fail-Soft Fallback:** Any cache miss, missing catalogue, invalid TOML, corrupted file, or decode error catches `(VisualSurfaceCacheError, AssetCatalogueError, KeyError, FileNotFoundError, OSError, ValueError, pygame.error)` and seamlessly renders `draw_soft_shadow`.

## 7. Failures Found and Corrected During Verification

1. **Remote Bridge Frame Capture Alpha Issue:** Pygame RGB screen surfaces have uninitialized/0 alpha bytes in memory on 32-bit SDL surfaces. `pygame.image.tobytes(surface, "RGBA")` caused PIL PNG export to output transparent pixels. Fixed in `src/greia_simulator/remote_bridge.py` by converting RGB bytes directly.
2. **AssetCatalogue.load TOML Error Handling:** `AssetCatalogue.load` did not catch `tomllib.TOMLDecodeError` when loading malformed catalogues. Fixed by wrapping TOML decode exceptions in `AssetCatalogueError` so that fail-soft fallback gracefully triggers.
3. **Tile Surface Cache Padding:** Updated tile cache surface padding (`pad_x=8, pad_y=12`) in `presentation.py` to ensure soft shadows at card bases are not clipped.
