# Code of Conduct

Greia adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct for everyone who takes part in the project: in issues,
pull requests, discussions, reviews and any other project space.

In short: be welcoming and respectful, assume good faith, give and accept
constructive criticism gracefully, and focus on what is best for the project
and the people who use it. Harassment, personal attacks, discriminatory
language and publishing other people's private information are not
acceptable.

## Greia is made for children

Because Greia's users are young children, contributions must also be
appropriate for them. Content, artwork, audio, names and example text that
would be unsuitable for a young child do not belong anywhere in the project.
Never include real children's names, photos, voices or personal data in
issues, fixtures or examples.

## Reporting

If you experience or witness unacceptable behaviour, contact the project
maintainer privately through GitHub (<https://github.com/frozenpepper>).
Reports are handled confidentially. Maintainers may remove contributions and
restrict participation as described in the Contributor Covenant's
enforcement guidelines.
