STEP 2 · WRITE THE INSTALLER TO A USB STICK

Flash it
in minutes.

Use the computer you have now. The download is a ready-made disk image (.img): it must be written to the stick, not copied onto it like a normal file.

EASIEST

balenaEtcher

  1. Install balenaEtcher ↗ and open it.
  2. Plug in the USB stick. Unplug any other USB drives so they can't be confused.
  3. Flash from file → choose the Greia .img you downloaded.
  4. Select target → pick the USB stick. Check its name and size: never your Windows disk.
  5. Flash! Accept the Windows permission prompt and wait for writing and validation to finish.
ALSO GOOD

Rufus or Raspberry Pi Imager

Rufus ↗: choose the stick under Device, press SELECT to pick the Greia image, then START. An .img is written as-is.

Raspberry Pi Imager ↗: Choose OS → Use custom → the Greia image, then choose the stick and Write.

Check the download (optional), in PowerShell:
Get-FileHash -Algorithm SHA256 "$HOME\Downloads\greia-os-installer.img"
The result must match the SHA-256 shown above.

After flashing, Windows may say it can't read the stick or offer to format it. Choose Cancel. That is normal: the stick now holds a Linux installer.

EASIEST

balenaEtcher

  1. Install balenaEtcher ↗ and open it from Applications.
  2. Plug in the USB stick, ideally with no other external drives connected.
  3. Flash from file → choose the Greia .img.
  4. Select target → the USB stick. Never your Mac's disk or a backup drive.
  5. Flash! Enter your Mac password if asked and let validation finish.
FOR TERMINAL USERS

Built-in dd

diskutil list                      # find the stick, e.g. /dev/disk4
diskutil unmountDisk /dev/disk4
sudo dd if=~/Downloads/greia-os-installer.img of=/dev/rdisk4 bs=4m
diskutil eject /dev/disk4

Replace disk4 with your stick's number. A wrong number overwrites another disk. Press Ctrl+T to see progress.

Check the download (optional):
shasum -a 256 ~/Downloads/greia-os-installer.img

After flashing, macOS may say the disk is not readable. Choose Ignore, not Initialize. Your Mac is only used to prepare the stick: this installer is not meant for installing Greia on a Mac.

EASIEST

balenaEtcher or GNOME Disks

  1. balenaEtcher ↗ (AppImage): Flash from file → Select target → Flash!
  2. Or open Disks, select the USB stick, open the ⋮ menu → Restore Disk Image…, choose the Greia .img and Start Restoring.
  3. Double-check you picked the stick, not your system disk.
FOR TERMINAL USERS

dd

lsblk                              # find the stick, e.g. /dev/sdb
sudo dd if=greia-os-installer.img of=/dev/sdb bs=4M status=progress conv=fsync

Use the whole device (/dev/sdb), not a partition (/dev/sdb1). Unmount it first if your desktop mounted it.

Check the download (optional):
sha256sum greia-os-installer.img
STEP 3 · START THE COMPUTER FROM THE USB STICK

Open the
boot menu.

Most computers show a one-time boot menu if you tap a key right after switching on. Pick your brand to see the usual key.

  1. 1

    Plug in and switch off

    Put the Greia USB stick in the computer that will receive Greia. Connect power, screen and keyboard. Shut the computer down completely.

  2. 2

    Tap the boot-menu key

    Switch on and immediately tap the key repeatedly (about twice a second) until a menu of devices appears.

  3. 3

    Choose the USB stick

    It may be listed as USB HDD, Removable device or by the stick's brand. Press Enter. The Greia splash and then the installer appear.

FIND YOUR BOOT KEY

F12

On older Acers the menu may be switched off: press F2 at power-on, set “F12 Boot Menu” to Enabled in the Main tab, save with F10.

Not listed or not working? The startup screen often says “Press … for boot menu”. Your computer's manual has the reliable answer.

Newer PC and the stick doesn't appear?

This preview is tested on legacy BIOS computers like the Acer Aspire One. Starting on newer UEFI PCs is included but still experimental. If the stick isn't listed, the firmware setup (usually F2 or Del at power-on) may need Secure Boot turned off or Legacy / CSM boot turned on. Only change settings you know how to change back, and never erase a disk to make it start.

IF SOMETHING GOES WRONG

Quick
fixes.

The computer starts its old system instead＋

The boot menu wasn't opened in time. Switch off fully, switch on and tap the boot key straight away. Try another USB port; front ports on desktops are sometimes not bootable.

The USB stick isn't in the boot menu＋

Re-write the stick and let validation finish. On newer UEFI PCs see “Newer PC and the stick doesn't appear?” above. Some very old computers can't start from every stick: try another one.

Etcher says validation failed＋

Download the image again, check its SHA-256 and try a different USB stick. Don't use a stick whose write failed.

No disk is offered in the installer＋

Stop there. Greia only offers internal disks it considers safe. Don't wipe or repartition anything by hand; write to us with the computer model.

Installation stopped with a message＋

Note or photograph the message. Nothing was erased if it stopped before you held the install button. Send us the message and computer model.

Can I go back to my old system?＋

Only by reinstalling it from its own recovery media. That's why the backup comes first.
