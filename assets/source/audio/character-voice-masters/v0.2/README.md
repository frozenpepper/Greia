# Canonical character master voices v0.2

Owner-selected and accepted on 19 October 2026: Lilli round 2 candidate 3; Leo round 1 candidate 3; Flash round 1 candidate 2; Dani round 2 candidate 3; Tito round 2 candidate 1; Momo round 2 candidate 3. The owner also accepted all 24 four-language evaluation samples and authorized adoption as the default voice-production identity set.

These six exact WAV masters superseded v0.1 for new production in October 2026. The active source set is now v0.3: Dani, Tito and Momo use new owner-selected masters; Lilli, Leo and Flash retain these exact bytes unchanged. v0.2 is kept as provenance for existing runtime assets and earlier accepted comparisons. Its canonical copies and `provenance.json` are historical and must not be overwritten.

Do not package authoring reference masters into Activities or child-device images. Existing accepted runtime recordings retain their accepted bytes and historical voice identities. A deliberate later replacement receives a new version and owner listening acceptance.
