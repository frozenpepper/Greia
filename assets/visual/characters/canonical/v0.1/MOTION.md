# Canonical Cast Motion Vocabulary (v0.1)

Semantic character motions defined for Greia characters:
- `idle_bounce`: Neutral state with periodic eye blink and subtle breathing lift
- `blink`: Bounded closed-eye state swap (~0.18s) with settle
- `happy_hop`: Joyful state swap + vertical parabolic hop
- `celebrate_pop`: High-energy pop with celebratory state
- `surprised_wobble`: Surprised state swap + recoil horizontal oscillation
- `sleepy_sway`: Sleepy state swap + slow gentle lateral sway
