# Forest / Meadow v0.2 — final restraint pass

**Status:** candidate desktop review.

Two target-size references now use the real pack assets:

- `reference_restraint_1024x600.svg` / `.png`
- `reference_restraint_800x600.svg` / `.png`

Changes from the earlier proof:

- default daytime composition no longer includes fireflies, dust motes or falling leaves;
- fog and sunlight opacity reduced;
- large trees/bushes frame the left/right edges instead of occupying the center;
- the central playfield remains intentionally quiet;
- foreground foliage is bounded to edge framing;
- 800x600 is separately composed rather than letterboxed from 1024x600.

The optional atmosphere/FX masters remain useful library assets, but they are no longer treated as simultaneous default layers. This closes the planned restraint pass at **DESKTOP VISUAL REVIEW** scope; owner approval and runtime/hardware acceptance remain separate.
