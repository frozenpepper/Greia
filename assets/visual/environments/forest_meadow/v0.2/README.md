# Greia Forest / Meadow Asset Pack v0.2

Status: **candidate reusable asset pack**.

This directory contains **individual SVG masters**, not a baked scene.

Purpose:
- establish the first environment family from reusable assets;
- provide far/mid/near/overlay layer roles for later parallax composition;
- provide atmosphere, shadow and ambient-FX primitives alongside props/foliage;
- keep the assets useful independently of any one Activity.

Current contents:
- 4 tree variants;
- 3 bush variants;
- fern, flowers, mushrooms;
- 2 rock clusters;
- fallen log + stump;
- 2 clouds;
- distant hills + distant tree line;
- grass edge + dirt playfield patch;
- sunlight + fog overlays;
- 2 contact-shadow variants;
- fireflies, dust motes, falling leaves.

Review rule:
weak assets must be revised/rejected individually before they are allowed to hide inside a composed scene.

The pack remains `runtime_consumed = false` until Greia's accepted catalogue/consumption seam is defined.
